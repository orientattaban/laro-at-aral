# curriculum

Put the official PDFs here. Claude Code reads them before writing any lesson and marks a lesson "verified" only when it finds the competency in one of these files.

  https://dswd.gov.ph/download/resource_materials/eccd_training_materials/LRP-1-28-pages-in-all.pdf
- [ ] ECCD Council, Standards and Guidelines for Center-Based Early Childhood Programs for 0 to 4 Years Old Filipino Children
  https://eccdcouncil.gov.ph/wp-content/uploads/2024/10/STANDARDS-AND-GUIDELINES-for-CENTER-BASED-FOR-ECCD-PROGRAMS-1.pdf
- [ ] Learning Resource Packages 5 and 6, the detailed activity plans, if your barangay Child Development Center can share them
